# Image credits

**Original launch photograph: SpaceX**, shared through [SpaceX's official X account](https://x.com/SpaceX), according to the source supplied to this project. The exact post URL and photographer name were not retained.

The original image is in `assets/launch-original.jpg`. Wallpaper editions, the comparison image, and embedded preview frames are color/exposure/HDR adaptations of that photograph. The spacecraft, launch site, clouds, and composition have not been redrawn or replaced. No generative imaging was used.
